# 爱看盘变现方案分析（2026-08-08）

前提约束：

- 行情数据授权尚未解决，不能把“实时行情”本身作为付费卖点。
- 当前定位为非商业/测试阶段，服务器还有约一年有效期。
- 没有企业主体、支付商户、投顾资质，C 端收费受限制。
- 产品强项：AI 复盘、涨跌停池、自选/持仓管理、研究台、盯盘、历史复盘、开源工程能力。

## 1. 现状盘点：现在真正能卖的是什么

| 资产 | 可卖性 | 说明 |
| --- | --- | --- |
| 行情展示 | 低 | 数据授权未解决，不能卖 |
| 投资建议/评分 | 低 | 有投顾资质风险，不建议卖 |
| AI 复盘工作流 | 中 | 可作为效率工具/模板卖 |
| 用户自己的数据资产 | 高 | 自选、持仓、复盘、计划、论点、导出，属于用户内容，合规风险低 |
| 私有部署/定制能力 | 高 | 给自媒体、工作室、团队做复盘工作台，数据由客户自备 |
| 内容/方法论 | 中 | 复盘模板、课程、社群，注意不能承诺收益 |
| 流量/广告位 | 低 | 目前没有流量，短期不可行 |

## 2. 变现路径对比

| 路径 | 卖什么 | 合规约束 | 启动成本 | 收入潜力 | 适合度 |
| --- | --- | --- | --- | --- | --- |
| B 端定制/私有部署 | 复盘工作台、品牌页、导出、API 适配 | 低；数据由客户自行授权 | 低 | 单子几千到几万 | 高 |
| AI 额度/会员 | 复盘导出、深度分析次数、模板 | 中；避免构成投顾 | 低 | 中 | 中 |
| 内容/社群 | 复盘方法论、模板库、圈子 | 中；不得承诺收益 | 低 | 中 | 中 |
| 广告/导流 | 广告位、券商开户导流 | 高；金融广告和导流资质严格 | 低 | 低（需流量） | 低 |
| 卖行情/卖评分 | 行情数据、AI 评分 | 高；数据授权+投顾资质 | 高 | 中 | 低 |

## 3. 推荐路径：先做 B 端，再做个人效率

### 阶段 0：继续免费积累（0-1 个月）

- 保持开源和免费使用，收集 D1/D7/D30 留存数据。
- 把现有站点当作“可演示的案例作品”。
- 目标：形成 2-3 个真实使用案例和一套复盘模板。

### 阶段 1：B 端定制 / 私有部署（最快见效）

目标客户：

- 财经自媒体：需要一个“每日复盘工作台”展示涨跌停、热点、自选命中。
- 投研工作室/小型团队：需要内部复盘、计划、持仓跟踪工具。
- 量化/编程团队：需要现成前端与 API 适配能力。

交付形态：

- 私有部署到客户服务器/自有域名。
- 数据接口由客户提供或客户自行获得授权。
- 定制品牌、复盘模板、导出报告（PDF/Markdown/CSV）。
- 按项目报价：基础部署 3000-10000 元，定制另计。

优势：

- 不依赖 C 端流量。
- 行情数据授权问题转移给客户自己处理。
- 一个订单即可覆盖一年服务器成本。

### 阶段 2：C 端个人效率付费（流量起来后）

可收费点（不卖行情、不卖建议）：

- 复盘报告导出（PDF/Markdown）。
- 多设备同步与数据备份。
- 自定义复盘模板。
- AI 摘要/诊断次数包（基于用户输入内容）。

合规要求：

- 需要企业主体 + 微信/支付宝商户号。
- 协议写明“AI 内容仅供参考，不构成投资建议”。
- 避免“保证收益”“荐股”“决策建议”表述。

### 阶段 3：内容与社群（可选）

- 复盘方法论、模板库、AI 提示词包。
- 付费圈子：每日复盘打卡、模板交流。
- 注意：内容不得承诺收益，不得以荐股方式运营。

### 阶段 4：广告/导流（流量足够后再考虑）

- 券商开户返佣、财经内容导流。
- 需要金融广告合规评估，且目前流量不足以支撑。

## 4. 不建议做的

- 直接卖行情数据或“实时行情会员”：数据授权未解决。
- 卖“AI 推荐股票/操作建议”：可能触及投顾资质。
- 用个人收款码做虚拟商品订阅：支付与退款风险高。
- 在测试期就上收费墙：会杀死留存，且没有支付合规基础。

## 5. 变现前需要准备的事项

1. 企业主体（个体户或公司）。
2. ICP 已备案；如有支付，需要商户号。
3. 数据授权决策：无论哪种变现，都需要先定数据模式。
4. 法务复核：收费服务条款、退款政策、AI 免责。
5. 留存数据：至少先跑 1-2 个月 D1/D7/D30，证明产品能留住用户。

## 6. 结论

最现实的启动路径是：

> **B 端定制/私有部署 1-2 单，覆盖一年成本；同时保留开源免费版积累案例；等数据模式、支付资质和留存数据都明确后，再做 C 端会员。**

不要在数据授权和投顾边界解决前，把“行情”或“投资建议”当成收费核心。
