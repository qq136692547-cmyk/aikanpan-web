# 0 成本启动方案（2026-08-08）

目标：不购买交易所行情许可、不采购持牌数据商，用 0 元成本把 aikanpan.top 继续跑起来。

## 约束澄清

0 成本、公开网站、实时 A 股行情三者只能满足两项：

- 要 0 成本 + 公开网站 → 不能对外复制展示第三方实时行情
- 要 0 成本 + 实时行情 → 只能个人使用/私有部署
- 要公开网站 + 实时行情 → 必须付费申请许可或采购数据商

推荐取舍：**0 成本 + 开源/个人项目 + 可对外访问**，数据层改为“用户输入 + 官方外链 + 可选免费非商用数据”。

## 方案 A：个人 / 私有模式（风险最低）

- 站点部署在本机或私有网络，只供自己使用。
- 可继续使用东方财富、新浪等免费接口，但仅限个人研究用途。
- 对外只开源代码，不公开部署实时行情实例。
- 成本：0 元（使用现有设备）。
- 风险：对本人使用而言很低，但仍属于使用平台接口，应遵守平台条款、降低请求频率。

## 方案 B：公开开源模板 + 用户自输入（推荐）

- 行情数据不复制展示：个股页只提供“查看官方行情”外链，指向东方财富、新浪财经、交易所官网等。
- 自选、持仓、交易流水、复盘笔记、计划、论点全部由用户手动输入。
- AI 复盘基于用户输入和公开资料生成，不承诺实时行情。
- 免费托管：
  - 前端：Vercel / Cloudflare Pages / GitHub Pages 免费额度
  - 数据库与账号：Supabase 免费额度
  - 后端：Vercel Serverless Functions / Cloudflare Workers 免费额度
- 成本：0 元；若保留 aikanpan.top 域名，仅有域名续费。
- 风险：不再复制第三方行情数据，合规风险最低，产品从“看盘”转为“个人复盘工具”。

## 方案 C：公开网站 + 免费数据源（有残余风险）

- 使用 Tushare Pro 免费积分、AkShare、baostock 等免费数据源。
- 只保留日线、延迟行情、收盘快照，不做实时五档。
- 页面显著标注：非商业个人研究用途、数据来源、未经交易所许可不得转载。
- 成本：0 元。
- 风险：公开网站仍属于再分发，可能违反数据源/交易所条款；不建议作为正式对外产品宣传。

## 实施步骤

1. 文案层：站点定位改为“非商业个人学习项目”，页脚增加“行情数据未经交易所许可不得转载”。
2. 数据层：默认关闭第三方行情拉取；个股页改为官方行情外链；自选/持仓改为用户输入。
3. 部署层：迁移到 Vercel/Cloudflare + Supabase，逐步下线付费云服务器。
4. 功能层：保留复盘、计划、论点、组合管理、AI 摘要，去掉实时行情依赖。
5. 验证：构建、测试、线上检查页面不再复制第三方行情数据。
6. 开源：现有 GitHub CI 保留，作为开源模板对外发布。
