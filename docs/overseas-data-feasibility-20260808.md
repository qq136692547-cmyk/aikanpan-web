# 海外数据接入可行性分析（2026-08-08）

结论：海外数据可以接，但要分三件事看：技术连通性、供应商条款、产品定位。**接 A 股数据不能绕开中国交易所授权；只有切到加密或美股等海外市场，才能用免费数据源真正降低合规风险。**

## 1. 服务器实测连通性（47.108.163.124）

| 数据源 | 实测结果 | 说明 |
| --- | --- | --- |
| api.coingecko.com | 200 | 可直接连接，加密数据 |
| twelvedata.com | 200 | 官网可达 |
| api.twelvedata.com | 超时 | 服务器无法直连，需代理 |
| api.coincap.io | 超时 | 需代理 |
| api.binance.com | 超时 | 需代理 |
| api.marketstack.com | 超时 | 需代理 |
| query1.finance.yahoo.com | 超时 | 需代理 |
| eodhd.com/api | 401 | 可达，缺 API Key，授权后可用 |

结论：中国服务器能直连的海外数据源很少；多数需要 Cloudflare Workers、海外 VPS 或服务器代理中转。

## 2. 供应商免费条款

| 数据源 | 免费额度 | 公开展示/再分发 |
| --- | --- | --- |
| CoinGecko | 免费 API，需署名 | 明确允许“非商业网站”个人使用并署名；商业使用需授权 |
| Twelve Data | 个人/非商业计划 | 再分发需单独购买 Redistribution Rights Add-On |
| EODHD | 免费计划 | 个人使用免费；商业/再分发需商业授权 |
| Marketstack | 免费计划 | 个人使用，再分发受限 |
| Yahoo Finance | 无官方稳定 API | 条款禁止爬取/再分发，且接口常变 |

## 3. 三种用法

### 3.1 用海外供应商接 A 股数据

- 技术上：部分供应商支持沪深交易所代码，如 EODHD、Twelve Data。
- 合规上：底层数据仍是沪深交易所数据，供应商免费计划也不允许公开网站再分发，**不能解决 A 股授权问题**。
- 结论：不建议作为 A 股产品的主数据源。

### 3.2 切到美股/全球市场

- 可用 EODHD、Twelve Data 等，免费计划仅限个人/非商业，公开站点再分发需要商业授权。
- TradingView 官方图表组件可嵌入部分行情，但商业网站仍需确认其许可条款。
- 结论：比 A 股合规压力小，但不是完全免费公开。

### 3.3 切到加密市场（0 成本最可行）

- CoinGecko 免费 API 可直接从当前服务器访问。
- 条款明确允许非商业网站个人使用并署名，公开的非商业站点风险最低。
- 加密数据无交易所许可概念，是 0 成本公开产品最现实的入口。
- 结论：如果目标是 0 成本 + 公开网站，加密数据是最优选择。

## 4. 接入方案

- 新增 `providers/overseas.py`，按 `QUOTE_PROVIDER` 切换数据源。
- CoinGecko 免费额度：公链、代币行情、历史 K 线、涨跌幅、市值。
- EODHD 可覆盖美股/全球 EOD，需要 API Key，免费额度小。
- 需要代理的源，用 Cloudflare Workers 做一次轻量转发和缓存，避免服务器直连被墙。
- 所有外部请求必须做缓存、限流、降级，避免免费额度被打爆。

## 5. 建议

- 如果继续做 A 股：海外数据解决不了授权，只能作为辅助（例如 TradingView 图表嵌入）。
- 如果接受换赛道：加密市场是 0 成本公开产品最可行的方向。
- 如果做美股：免费层只适合个人/演示，公开商业使用仍要买授权。

> 本报告为公开资料与技术实测，不构成法律意见。


## 6. A 股 + 美股双市场方案

### 6.1 服务器连通性补测（2026-08-08）

| 美股数据源 | 服务器直连 | 具体结果 |
| --- | --- | --- |
| Finnhub | 可连 | API 返回 401，表示网络通但需有效 API Key |
| Twelve Data | 可连 | API 返回 401，网络通 |
| EODHD | 可连 | 返回 401，网络通 |
| Polygon | 可连 | 根路由 404，API 域名通 |
| Alpha Vantage | 不可连 | 超时 |
| Yahoo / Marketstack | 不可连 | 超时 |

结论：美股数据从当前服务器可直接接入 Finnhub、Twelve Data、EODHD、Polygon，不需要代理。

### 6.2 双市场架构建议

- 后端新增 `providers/us.py`，按市场选择数据源：A 股保持现有源，美股用 Finnhub / Twelve Data / EODHD。
- 前端新增市场切换（A 股 / 美股），同一套首页、个股页、自选、持仓架构复用。
- 所有外部请求必须做缓存和限流，避免免费额度被打穿。
- 免费层只适合测试期；商用前需买不同数据源的再分发权益或商业计划。

### 6.3 法律边界：“只做中国市场”不意味着海外规则不适用

- 海外数据商条款是合同，不因你只面向中国用户就无效；对方可以停止服务、封网络或追约。
- 网站、服务器、用户都在中国，《网络安全法》《数据安全法》《反不正当竞争法》等中国法仍适用。
- 美股行情下层来自纽约/纳斯达克等交易所，同样有行情数据授权体系；免费 API 通常不是合法的再分发途径。
- 若提供美股“评分/建议”给中国用户，仍可能触及投资咨询管控；仅展示行情工具属性的风险相对较低。
